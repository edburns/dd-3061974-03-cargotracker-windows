Research established that `CargoRoute` exposes formatted text rather than a `Date`: its full arrival-deadline string begins with `MM/dd/yyyy`, while the table displays the date-only representation. A per-load parser preserves the DTO contract and avoids mutable formatter sharing. Implement this finding from scratch without reading or adapting spike code.

## Implement

Create:

- `src/main/java/org/eclipse/cargotracker/interfaces/booking/web/ChangeArrivalDeadlineDate.java`

Use this bean shape:

```java
@Named
@ViewScoped
public class ChangeArrivalDeadlineDate implements Serializable {
    private static final long serialVersionUID = 1L;

    private String trackingId;
    private CargoRoute cargo;
    private Date arrivalDeadlineDate;

    @Inject
    private BookingServiceFacade bookingServiceFacade;
}
```

Provide:

- `getTrackingId()` / `setTrackingId(String)`
- `getCargo()`
- `getArrivalDeadlineDate()` / `setArrivalDeadlineDate(Date)`
- `load()`
- `changeArrivalDeadline()`

`load()` must call `bookingServiceFacade.loadCargoForRouting(trackingId)`, retain the returned `CargoRoute`, parse the leading date portion of `cargo.getArrivalDeadline()` with a newly created `SimpleDateFormat("MM/dd/yyyy")`, and store the result. It must not query repositories or domain objects. Surface malformed DTO data as a clear application/view error consistent with neighboring JSF code; do not swallow, print, or convert the failure to null.

`changeArrivalDeadline()` must reject a null selection through JSF validation or explicit bean validation, invoke `bookingServiceFacade.changeDeadline(trackingId, arrivalDeadlineDate)`, and only after successful delegation call:

```java
PrimeFaces.current().dialog().closeDynamic("DONE");
```

Do not close the dialog if delegation fails.

Add a container-free JUnit test if practical with a hand-written fake facade. Discriminate:

- correct tracking ID on load;
- conversion of an `MM/dd/yyyy` leading DTO date to an editable `Date`;
- selected date and tracking ID delegated on submit;
- malformed DTO date is surfaced;
- null selected date is rejected;
- failed facade submission does not execute success-close behavior where that interaction can be tested without a container.

## Completion gates

- The bean is serializable and uses the established CDI/JSF annotations.
- It references facade contracts and DTOs only, never domain model or repository classes.
- Parsing and submission failures are explicit and not success-shaped.
- `./mvnw clean package -Popenliberty` succeeds on JDK 17.
- All earlier application/facade gates remain intact.

- A future/minimum deadline rule, new mocking dependency, runtime modernization, feature-bearing commits, or spike source.
