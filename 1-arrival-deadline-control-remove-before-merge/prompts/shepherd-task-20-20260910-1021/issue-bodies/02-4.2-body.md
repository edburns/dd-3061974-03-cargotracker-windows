## Implement

Modify:

- `src/main/java/org/eclipse/cargotracker/interfaces/booking/facade/BookingServiceFacade.java`
- `src/main/java/org/eclipse/cargotracker/interfaces/booking/facade/internal/DefaultBookingServiceFacade.java`

Optionally add a focused container-free test at:

- `src/test/java/org/eclipse/cargotracker/interfaces/booking/facade/internal/DefaultBookingServiceFacadeTest.java`

Add the facade API:

```java
void changeDeadline(String trackingId, Date arrivalDeadline);
```

Delegate exactly as follows:

```java
bookingService.changeDeadline(
        new TrackingId(trackingId),
        arrivalDeadline);
```

The facade converts only the identifier. It must pass the same deadline value/object through unchanged and must allow application/domain failures to propagate according to existing conventions.

If a focused test is practical without a container, use a hand-written `BookingService` fake or spy and prove:

- the string becomes an equivalent `TrackingId`;
- the same `Date` reaches `BookingService`;
- delegation occurs exactly once;
- the facade performs no repository or aggregate work.
